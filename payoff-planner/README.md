Solutions for the freelancer assignment, written in JavaScript and React.

## Problem 1: Longest Substring Without Repeating Characters
File: `longest-substring.js`
Run it with: `node longest-substring.js`

## Problem 2: Longest Palindromic Substring
File: `longest-palindrome.js`
Run it with: `node longest-palindrome.js`

## Problem 3: Credit Card Payoff Planner
Folder: `payoff-planner` (React app built with Vite)

To run it:

1. `cd payoff-planner`
2. `npm install`
3. `npm run dev`
4. Open the link shown in the terminal (usually http://localhost:5173/)

Enter a balance, an APR (0 to 100) and a monthly payment, then click Calculate to see the month-by-month table and the interest summary.
